# ⚔️ Mystic Roguelike RPG

A **text-based roguelike RPG** built in **Python**, where every run is unique.  
Battle monsters, learn spells, and discover elemental reactions to survive in a world that constantly evolves.

---

## ✨ Key Features

- 🎲 **Randomly generated monsters**: each encounter is different, with creatures that **level up over time**.
- 🔮 **Magic system**: unlock new spells as you level up and combine elements for special effects.
- 🧪 **Items and consumables**: potions, scrolls, and artifacts that can change the course of battle.
- 📈 **Character progression**: gain experience, level up, and become stronger.
- 🌪️ **Basic elemental reactions**: fire, water, rock, grass and ice and interact, creating strategic advantages and disadvantages.
